# 🎓 Student Result Management System

This is a simple Student Result Management System made in Python using Object-Oriented Programming (OOP). The project allows a teacher to assign marks to a student, and the student can then view their result.

## Features

* Create students and teachers
* Assign marks to students
* View student results
* Save assigned marks in a text file
* Demonstrates inheritance between different classes

## OOP Concepts Used

* Classes and Objects
* Inheritance
* Encapsulation
* Constructors
* Method Usage

## File Handling

The project uses a text file (`results.txt`) to save the student's name and assigned marks.

## Project Structure

```text
Student-Result-Management-System/
│
├── student_result.py

└── README.md
```

## Technologies Used

* Python 3

## About This Project

I created this project to practice Object-Oriented Programming and basic file handling in Python. It helped me understand how inheritance can be used to create different types of people, such as students and teachers, and how their roles can interact with each other.
